# Smart RADAR Object Tracking & Threat Detection Simulator

## Overview

A real-time RADAR simulation system built using C++17 and SFML.

The application simulates:
- RADAR scanning
- Object tracking
- Threat detection
- Collision alerts
- Real-time visualization

---

## Features

- Multiple moving targets
- Threat classification
- Collision detection
- Multithreaded updates
- Real-time rendering
- Object logging
- Coordinate tracking

---

## Technologies

- C++17
- SFML
- STL
- Multithreading
- OOP
